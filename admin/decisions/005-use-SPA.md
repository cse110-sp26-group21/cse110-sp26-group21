# ADR: Use a Single Page Application (SPA)

## Status
Accepted

## Context
We need to decide whether to build the application as a single page application (SPA) or a multi-page application (MPA).

## Decision
We will build the application as a single page application (SPA).

## Consequences
Pros:
- Faster navigation without full page reloads
- Better user experience with smoother interactions
- Works well with React and client-side routing

Cons:
- Larger initial page load
- More reliance on JavaScript being enabled
