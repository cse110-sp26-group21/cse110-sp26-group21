# Team 23 Feedback

## Strengths
I like how detailed and organized the repository is. The project structure is easy to follow, and the README clearly explains where important documents and source files are located. It is also nice that the team included architecture documents, ADRs, user stories, and testing information because it shows strong planning and teamwork. The deployed website link also makes the project easy to access and try.

## Improvements
The README contains a lot of useful information, but some sections could be shortened or simplified for new visitors. Adding a few screenshots or GIFs of gameplay near the top could also help people quickly understand what the game looks like before reading the full documentation.

## Question
How do you plan to keep the gameplay challenging and fun for players who already type quickly?

## Suggestion
It could be interesting to add different difficulty levels or coding themes so players can practice different types of syntax while keeping the game replayable.
