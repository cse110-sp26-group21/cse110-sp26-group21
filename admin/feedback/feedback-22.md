# Team 22 Feedback

## Strengths
I think the repository is organized well because the folders are clearly separated into `src`, `tests`, `docs`, and `planning`, which makes the project easier to navigate. The README also explains the team workflow and development process clearly. In addition, the background art and plant graphics make the game feel creative and visually interesting.

## Improvements
The README contains a lot of useful information, but it feels a little long for first-time users. Maybe adding a short quick-start section near the top would help people understand how to run the project more quickly. I also think adding more screenshots or gameplay previews could help show the main features of the game more clearly.

## Question
Are you planning to add more gameplay features besides typing practice in the future? It would be interesting to see how the game could expand while still keeping the educational typing focus.

## Suggestion
It could be cool to add small animations or sound effects when the plants grow to make the game feel more interactive. A progress or reward system could also encourage players to keep practicing typing over time.
