# Team 22 Feedback

## Strengths
The repository is organized well because the folders are clearly separated into `src`, `tests`, `docs`, and `planning`, which makes the project easier to navigate. The README also explains the team workflow and development process clearly. In addition, the background art and plant graphics make the game feel creative and visually interesting. Actual gameplay is very intutitve and easy for user's to pick up quickly. The specific coding snippets used do a great job of balancing difficulty while teaching valuable coding concepts, such as function definitions and for loops. Overall very fun and engaging game, we are excited to see the final product!

## Improvements
The README contains a lot of useful information, but it feels a little long for first-time users. Maybe adding a short quick-start section near the top would help people understand how to run the project more quickly. I also think adding more screenshots or gameplay previews could help show the main features of the game more clearly. For the actual gameplay, it might be clearer to mark typos in red, so the user know's what they need to correct and it isn't as confusing when the game doesn't let them progress to the next code block. Additonally, when the user hit's retry, it doesn't seem to properly reset the game and the user get's stuck on the gameplay screen.

## Questions
Are you planning to add more gameplay features besides typing practice in the future? It would be interesting to see how the game could expand while still keeping the educational typing focus. What other languages do you plan to incorporate and how big do you anticipate your code snippet json files to get?

## Suggestion
It could be cool to add small animations or sound effects of plants growing when a code snippet is correct to make the game feel more interactive. A progress or reward system that let's user's buy flowers or expand their garden could also encourage players to keep practicing typing over time.

Great work and progress!
