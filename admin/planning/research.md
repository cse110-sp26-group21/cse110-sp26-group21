### Typing.com, Z-Type
_**Description:**_ Typing.com is a site that has 6 different typing game options with different difficulties and themes. Ztype is a space invaders esque game where words fall down the top of the screen towards your spaceship and you must type to destroy them. 

_**Notes:**_
- With each character typed, a bullet is shot at the word you are currently target and the letter disappears
- Words seem to be random and not related to the game 
- Once you start a word, you cannot switch to another word on the screen until you complete the current word, the one you are working on gets highlighted
- If a word gets to your spaceship the game ends and you are displayed a final score, wave reached (level), accuracy, and longest streak (across games)
- For each wave the words increase in frequency and speed at which they move down the screen

### MonkeyType
_**Description:**_ minimalist online typing test website designed to measure and improve typing speed and accuracy. 

_**Notes:**_
- Test speed and accuracy when typing a bunch of randomly generated words bunch together in a paragraph 
- Can continue typing to the next characters even if you get one wrong, or you can backspace to correct it
- Test runs for 30s (can be adjusted in settings)
- Post test shows you wpm, accuracy, total characters type, and your consistency
- You can adjust the theme, gamemode (essentially language you type in), difficulty, and more in settings 
- There is a leaderboard of players 

### NitroType
_**Description:**_ free, browser-based competitive typing game where players race cars against others in real-time by typing text prompts quickly and accurately.

_**Notes:**_
- Fast paced, cool artstyle but no CRAZY animations
- Can win achievements for completing races, winning races, collecting money, and more
- Can use collected money to customize your race car 
- Can add friends and create teams 
- Only one game function: races 
- During a race, you type a blurb of text about a random subject. The words and sentences are syntax-ly correct and relevant to each other (not random words)
- You cannot move on to the next character until you’ve typed the correct one of the word you are currently typing
- Car speeds up as you type words correctly quickly, you can also earn boosts through the race that you activate by clicking enter
- You are evaluated on WPM, accuracy, and total time
- The higher you rank, the more money and XP you collect 


### Keys of Fury
_**Description:**_ 2d retro style fighting game that allows players to fight enemies by typing words and phrases. Must be purchased for $5. The words don’t seem to be related to the actions being done and are randomly generated most of the time. 

_**Notes:**_
- Lots of fast paced action after words are typed correctly 
- Words/phrases appear on the screen and stay until fully typed. Roughly each character type is like a punch or kick. Need to quickly type before the enemy can attack
- Word/phrase is sometimes disappearing and reappearing or you have to type multiple words at once before real damage is done
- One unique thing was at a point 3 fruit were thrown at you, and had to type 3 distinct characters to break them
- Later they were whole words 
- One stage requires you to type words quickly to outrun dinosaurs
- Minigame where you type out corny jokes
- Only 3 short stages out right now so very quick

### Haolong Chen
Our team chose Nitro Type as the main reference for our project idea. We believe we can create a simplified version of the game using only HTML, CSS, and JavaScript. Instead of copying the original car racing concept exactly, we plan to use our own custom character or avatar system.
In our version, the player’s avatar will move forward whenever the player types a code snippet correctly. This gives players visual feedback and makes the game feel more interactive and engaging than a traditional typing test.
We also discussed adding custom avatars inspired by each team member. This would make the project feel more personalized and unique to our group while still keeping the gameplay simple and easy to implement.
The overall goal is to create a fun typing game that helps users improve coding syntax familiarity and typing accuracy in an enjoyable way.

**Journey Mapping**
1. The player opens the game.
2. The player selects a custom avatar.
3. The game displays a code snippet for the player to type.
4. The player types the code snippet.
5. Correct typing causes the avatar to move forward.
6. The player receives feedback such as progress, speed, or accuracy.
7. The round ends when the snippet is completed.
8. The player can restart or try another challenge.
