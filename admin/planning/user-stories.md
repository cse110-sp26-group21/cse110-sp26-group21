# User Stories

As a beginner coder, I want to practice typing code snippets, so that I can improve my speed and accuracy with syntax.

As a player, I want my avatar to move forward when I type correctly, so that I can get visual feedback and feel progress.

As a team member, I want custom avatars based on our group, so that the game feels personalized and unique.

---

**User Story 1 — The Learner**
As a young student new to coding, I want to destroy incoming meteors by typing HTML code snippets correctly in order to learn basic web development syntax in a fun and engaging way.

**User Story 2 — The Returning Player**
As a returning player, I want to see my streak and progress tracked between sessions in order to stay motivated and keep coming back to practice coding skills.

**User Story 3 — The Educator**
As a teacher or parent, I want to select a specific difficulty level (HTML, CSS, or JavaScript) in order to ensure my student or child is practicing code appropriate for their skill level.
